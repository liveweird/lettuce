# Telemetry panel (`web/`) — v4.20.0

Moved out of `web/CLAUDE.md` so it is read on demand; `web/CLAUDE.md` keeps a mandatory-read pointer. The server side (sampler, tables, read API, retention): `.claude/docs/features/telemetry.md`; the wire: `GET /api/v1/telemetry/current` and `/history` (ADMIN only, 30 requests a minute per user), `api/telemetry.ts`. Ported from Toadie 2.28.0's panel (itself Flow's); Lettuce's sections are **Memory · Database · Requests · JVM** (no Pressure: Lettuce has no in-process bounded things — decision D1; the database pool lives under Database — D2).

## The aside and the toggle

- **Not a feature flag, not a nav leaf, no tour step** (D8): ADMIN tooling inside the existing user menu (the `TutorialsSubmenu` precedent). `App.tsx` `Shell` gives `AppShell` `aside={{ width: 420, breakpoint: "lg", collapsed: { desktop: !showPanel, mobile: !showPanel } }}` — beside the content from 1200 px up, covering the page edge to edge below it (a pushed 420 px next to the navbar would leave a sliver). The aside element is rendered **only while shown** (`{showPanel && <AppShell.Aside aria-label=… />}`), so a closed panel paints and reserves nothing — the 24 desktop visual baselines (menu closed, flag false) cannot move. The panel is `<AppShell.Aside>` wrapping its OWN `ErrorBoundary` (`fallback={<TelemetryPanelCrash onClose=… />}`: the open flag survives a reload, so a render crash would otherwise loop; `ErrorBoundary` gained the optional `fallback` prop) and a `Suspense` (`CenteredLoader`) around the **lazy** `TelemetryPanel` chunk (`lazyPage`, so a non-admin never downloads it). `showPanel = isAdmin() && useTelemetryPanelOpen()`: a stored `true` never shows anything to a non-admin and requests nothing.
- **The toggle** is `hooks/useTelemetryPanel.ts` — `useSyncExternalStore` over `readStoredJson("telemetry.panelOpen")` (device key `lettuce.viewSettings.telemetry.panelOpen`, default closed) with a module-level listener set (the `useChangelogSeen` idiom). Two writers through `setTelemetryPanelOpen`: the `HeaderUserMenu` ADMIN-only item "Telemetry panel" (check mark + `aria-current` while on — Mantine fixes the item's role) and the panel's own close X. **Keyboard path (v4.20.1):** opening from the menu moves focus to the panel's h2 (`tabIndex={-1}`), via a one-shot module-level request (`takeTelemetryPanelFocusRequest`) the panel consumes on mount — a panel restored open by a reload takes no focus. An OPEN is deliberately not flushed: it must commit with the menu's own close, which hands focus back to its button 10 ms later only when focus has not moved meanwhile. Below `lg` the panel covers the page, so the navbar and `<main>` are `inert` while it is open (the header stays usable). Closing is committed first (`flushSync` — an inert `<main>` cannot take focus), then moves focus to `#main-content`.

## Queries

One `useQuery(["telemetry","current"])`: `refetchInterval` 60 s, `refetchIntervalInBackground: false`, `staleTime` 30 s (the panel is mounted only while open, so the poll stops with it). A failed first load is a red `Alert` (`loadErrorMessage`, never `error.message` — `TelemetryLoadError`), a failed refresh over existing figures keeps them under a titled "may be out of date" Alert, an orange `Alert` per stale process. Each section's trend is its own `useQuery(["telemetry","history",group,range])` (`staleTime` 5 min, `placeholderData: keepPreviousData` shown dimmed with `aria-busy`, **`enabled: active`** — only an expanded section requests its history). Keep the `["telemetry", …]` prefix: no mutation invalidates it and the session-boundary cache clear already empties it. Read-only: no success toast.

## The panel (`components/TelemetryPanel.tsx`)

Header (h2 title, "Sampled at …" via `formatDateTime(ts, i18n.language)`, the close `ActionIcon`, a 24 h / 7 days / 90 days `SegmentedControl`) and an `Accordion multiple order={3}`. The range (`telemetry.range`) and the expanded sections (`telemetry.sections`, default `["memory"]`) are `useStoredState` with `isOneOf`/a list validator, so corrupt stored state falls back. A section body renders once opened so it can finish its close transition; its history runs only while `active`. Labels go through literal `Record<…, ParseKeys>` maps (`SECTION_LABELS`, `RANGE_LABELS`, and `utils/telemetryNames.ts` for the server's nine table-group and 14 counted-table names — an unknown name reads as itself), never template keys.

- **Memory**: per process the container limit (or "No limit"), working set, the share of the limit with a TEXT badge ("High" from 80 % orange, "Critical" from 90 % red — never colour alone), container peak, heap, old-gen peak, non-heap, direct, RSS; trend = the share of the limit when a limit is known, else bytes, else the heap.
- **Database**: per process the connection pool "n of `limits.poolMaxSize`" (in use, idle, waiting, open), then the database size and the nine table groups, "measured at" (hourly), and the row count of each counted table; **three** trend sets from ONE `group=database` request (`databaseSets`: pool peaks, bytes, counts), each with its own chart and table.
- **Requests**: the window note (counts window and `percentileWindowSeconds`), a table of `*` plus the busiest routes (every routed `/api/v1/` and `/integration/` template is labelled server-side, the telemetry's own excluded) — count, p50, p95, a red 5xx and an orange 429 badge — in `TelemetryScrollRegion` (a native `Table.ScrollContainer` that is itself a named, `tabIndex={0}` `role="group"`: axe `scrollable-region-focusable`); trend = p50/p95 of `*`.
- **JVM**: CPU, threads, GC of the last interval; trend = CPU.
- **The trend** (`TelemetryTrend.tsx`): the section passes `sets(series, t) → TrendSet[]` (the pure column builders in `utils/telemetryTrend.ts`: `memoryColumns`, `databaseSets`, `requestsColumns`, `jvmColumns`, `oneSet`, `trendTimes`, `chartRows`); each set is one lazy `TelemetryTrendChart` plus its figures table behind `FiguresDisclosure`. Notes: "History starts <date>" when `historyFrom > from`, "More lines matched than are listed" when `truncated`.
- **Formatting** (`utils/telemetryFormat.ts`): deterministic and language-neutral symbols (binary B/KB/MB/GB so a 512 MB container limit reads "512 MB", ms/s/min/h/d, counts with a no-break space between thousands, `memoryLevel`); "n of N" is `usageOf` in `utils/telemetryNames.ts`.

## Charts (the panel's trends)

- **Applies when:** adding or changing a multi-line chart (`@mantine/charts` over recharts; `TeamKpiChart` is the older single-line one).
- **Requirement:** a chart is a **lazy chunk only** (`lazy(() => import("./XChart"))` behind a `Suspense` with `CenteredLoader`) that **imports `@mantine/charts/styles.css` itself** — recharts and the stylesheet never enter the entry bundle. **One axis, one unit per chart** — a section with several units draws several charts, never a dual axis. A **legend only from two lines up**. Colours come from `utils/chartColors.ts` (`CATEGORY_PALETTE`/`lineStyle`: seven Mantine shades in a fixed, validated order — ≥ 3:1 on white, the `#f8f9fb` canvas and the dark body/canvas greys, adjacent ΔE ≥ 15, none of the app's semantic red/orange/teal/brand green; re-validated for Lettuce's four surfaces with the dataviz skill's `validate_palette.js` in v4.20.0 — all gates pass; `lime.9`, the one green-adjacent entry, stayed because its only validated replacement `yellow.9` fails the dark lightness band and the light-canvas contrast) and **colour is never the only carrier of meaning**: each line past the first also wears its own dash pattern, the legend and tooltip name every line, and **every chart's numbers are available in a table** behind `FiguresDisclosure` (an `aria-expanded`/`aria-controls` button, the body unmounted while closed, the table in a named, focusable scroll region). A chart never draws more lines than the palette has colours (the bytes chart plots the database + the first six groups; the rest stay in the table). The chart wrapper carries `role="group"` + an aria label. recharts renders the tooltip content while inactive with an undefined label: `TrendTooltip` draws nothing then, and the tick/value formatters are guarded the same way.
- **Reference:** `components/TelemetryTrendChart.tsx`, `components/TelemetryTrend.tsx`, `components/FiguresDisclosure.tsx`, `utils/chartColors.ts`.
- **Enforcement:** `chartColors.test.ts` (contrast, neighbour distance, dash patterns), the `TelemetryTrend*.test.tsx` suites; tests mock `@mantine/charts` (recharts has no layout under happy-dom); the entry-bundle size is read off `perf/web/bundle-report.mjs`.
