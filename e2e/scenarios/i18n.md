# Language switch

- **Spec**: [tests/i18n.spec.ts](../tests/i18n.spec.ts)
- **Actors**: the seed administrator
- **Owns** (exclusive server-side state): nothing — read-only (the language choice lives
  client-side only)

## Scenario: language switch to Polish persists across reload

1. The admin signs in and lands on the dashboard.
   - *Expected*: the **Dashboard** heading is visible (English chrome).
2. Any active alert banner overlaying the header is hidden first — by design the user collapses
   it before reaching the header controls, and the collapse itself persists across the reload.
3. The admin opens the header language menu and picks **Polski** (entries are the
   languages' native names, readable before switching).
   - *Expected*: the chrome translates to Polish — the **Pulpit** heading and the
     **Moi podwładni** tab are visible.
4. The admin reloads the page.
   - *Expected*: still Polish — the **Pulpit** heading is visible; the choice persisted.
5. The admin opens the language menu again and picks **English**.
   - *Expected*: back to English — the **Dashboard** heading is visible. Ending on EN is
     courtesy hygiene, not a cross-spec dependency (each test gets a fresh browser context).
